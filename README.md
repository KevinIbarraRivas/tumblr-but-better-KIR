# Project 5 - Tumblr Feed

Submitted by: **Kevin Ibarra Rivas**

**Tumblr Feed** is an app that fetches and displays a scrolling list of blog posts from the Tumbirbs Tumblr blog, showing each post's photo and summary text.

Time spent: **7** hours spent in total

## Required Features

The following **required** functionality is completed:

- [x] App has a configured table view and table view cell
- [x] App populates the table view with data fetched from an API

The following **optional** features are implemented:

- [x] App fetches posts from a different Tumblr blog
- [x] Pull-to-refresh control to update the table view
